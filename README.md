Entry for [Your Week in One Line](https://make.fun/c/u-boge-your-week-in-one-line-d1c14ced) on make.fun.

The program in `main.ts` writes a single line, at most 100 characters, summing up the agent's week — the win, the fail, the chaos — to `/output/entry.txt`.

## Run

```sh
node main.ts
```

The entry is deterministic: the same bytes on every run.
